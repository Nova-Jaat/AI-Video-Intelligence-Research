## 🧠 The Framework at a Glance

```
[ Ad / Traffic ]
      ↓
[ Landing Page ]  ←  $7–$27 Core Digital Product
      ↓
[ Checkout Page ] +  [ Order Bump ]  → +$10–$20
      ↓
[ OTO Upsell Page ]  → +$27–$97
      ↓
[ Thank You Page ]  →  Email List (Buyer)
```

**Goal:** Turn a $7 product into a $25–$50+ avg. transaction. Use ad spend as a *self-funding* customer acquisition machine.

## 📍 Phase 1 — DEFINE (Do This First)

### 1.1 — The Rule of Ones (Foundation)

Before building anything, lock these in:

```
ONE Niche    →  Who is your exact customer? (e.g., "beginner freelancers")
ONE Problem  →  What single painful problem do you solve?
ONE Product  →  One low-ticket item, NOT a full course
ONE Funnel   →  All traffic goes here, no scattered offers
```

**Action:** Fill in the blanks:

```
My customer is: _______________________________________________
Their #1 painful problem is: __________________________________
My product solves it by: ______________________________________
My product name idea: _________________________________________
```

---

### 1.2 — Viral Product Checklist

Your product MUST hit all 3 viral triggers:

| Trigger | What It Means | Your Product ✓? |
|---------|--------------|-----------------|
| 🔥 **Curiosity** | The name/concept makes people stop & click | [ ] |
| ⚡ **Instant Value** | Customer gets a quick, satisfying WIN fast | [ ] |
| 🔍 **Searchable Name** | People would actually Google this phrase | [ ] |

> IMPORTANT: If your product concept doesn't pass all 3, **rename or reframe it** before building. The name drives virality more than the content.

**Viral Name Templates:**
- `"The [Time Frame] [Result] Blueprint"`
- `"[Number] [Niche] Templates That [Outcome]"`
- `"The [Adjective] [Skill] Cheat Sheet"`
- `"How to [Specific Result] in [Short Time] (Even If [Objection])"`

| Type | Build Time | Tools | Price Range |

| PDF Guide / Checklist | 2–4 hrs | Canva, Notion | $7–$17 |

> TIP: **Don't start from scratch.** Repurpose knowledge you already have — a past presentation, notes, process you use daily. The fastest products win.

### 2.2 — Product Build Checklist

```
[ ] Topic chosen + passes viral trigger test
[ ] Outline written (5–10 key points max)
[ ] Content created (PDF / Notion / Video)
```

## 📍 Phase 3 — BUILD THE FUNNEL

### 3.1 — Landing Page (The Front Door)

**Rule:** Keep it SIMPLE. One page. One offer. No navigation menu.

**Landing Page Structure:**
```
┌─────────────────────────────────────────────┐
│  HEADLINE: Big bold promise / transformation │
│  SUBHEADLINE: Who it's for + how fast        │
│  [PRODUCT MOCKUP IMAGE]                      │
│  3–5 Bullet Points (what they GET / RESULTS) │
│  Social Proof / Testimonials (even 1–2)      │
│  [BUY NOW — $7] ← Big, clear CTA button      │
└─────────────────────────────────────────────┘
```

**Copy Formula for Headline:**
```
"[Get/Steal/Copy] the exact [thing] I used to [result] — 
even if you [common objection]."
```

> NOTE: The mockup image is critical. Even a PDF needs a visual 3D cover. Use free tools like [Smartmockups](https://smartmockups.com) or Canva's mockup templates.

### 3.2 — Checkout Page + Order Bump

**Order Bump Formula:**
```
Checkbox: "YES! Add [Complementary Item] for just $[X] →"
  - Must be a natural add-on to the main product
  - Price: $9–$19 (should feel like a no-brainer)
  - Example: Main = "30 Instagram Caption Templates" 
             Bump = "10 Matching Story Slide Templates"
```

**Checklist:**
```
[ ] Order bump offer created
[ ] Copy written (1–2 sentences max, benefit-led)
[ ] Price set ($9–$19)
[ ] Connected to checkout page
```

### 3.3 — Upsell / OTO Page (One-Time Offer)

Triggered immediately after main product purchase, before thank-you page.

**OTO Formula:**
```
"Wait! Before you access [Core Product]..."
"Now that you have [X], you're going to need [Y] to [result faster]."
"This is a one-time offer — it goes away when you leave this page."
[ YES, ADD THIS ] ← One-click button (no re-entering payment)
[ No thanks, I'll figure it out myself ] ← Decline link
```

| OTO Level | Price Point | Type of Offer |
|-----------|------------|---------------|
| OTO 1 | $27–$47 | Deeper resource, advanced templates, vault |
| OTO 2 (optional) | $47–$97 | Implementation workshop, done-for-you assets |

**Checklist:**
```
[ ] OTO offer created
[ ] OTO page written and built
[ ] 1-click upsell connected (via SamCart / ThriveCart)
[ ] Thank-you page built with clear delivery instructions
```

## 📍 Phase 4 — TRAFFIC (Ads That Pay for Themselves)

### 4.1 — The Revenue Math First

Before spending on ads, know your numbers:

```
Front-End Product:        $7
Order Bump (avg 30%):    +$4.50  (30% of customers add it at $15)
OTO (avg 20%):           +$7.00  (20% of customers take it at $35)
─────────────────────────────
Average Order Value:     ~$18.50

If ad cost per purchase = $10 → Profit per customer = $8.50 ✅
If ad cost per purchase = $20 → Loss = -$1.50 (optimize or add OTO 2)
```

> IMPORTANT: **Know your AOV (Average Order Value) before scaling ad spend.** Run with $5–$10/day until you have data, then scale what's profitable.

### 4.2 — Meta Ads Setup (Facebook/Instagram)

**Ad Types that work:**
1. **Story Ads** — Vertical, raw, authentic (phone-recorded works great)
2. **Feed Reels** — 15–30 sec, hook in first 3 seconds
3. **Carousel Ads** — Show each benefit as a slide

**Ad Hook Formulas:**
```
"I made $[X] selling a $7 PDF — here's how →"
"Stop [bad habit]. Do [this] instead →"
"The [niche] cheat sheet nobody is selling (but should be) →"
"POV: You just bought a $7 guide that actually changed everything →"
```

**Campaign Structure:**
```
Campaign: Conversions (Purchases)
  └── Ad Set: Broad targeting / Interest stack
        ├── Ad 1: Story format (hook A)
        ├── Ad 2: Feed video (hook B)
        └── Ad 3: Static image + strong headline
```

**Checklist:**
```
[ ] Meta Business Manager set up
[ ] Facebook Pixel installed on landing page
[ ] 3 ad creatives made (video/image)
[ ] 3 ad copy variations written
[ ] Campaign launched at $5–$10/day
[ ] Tracking: purchases, AOV, ROAS monitored daily
```

## 📍 Phase 5 — SCALE & OPTIMIZE

### 5.1 — Key Metrics to Track Daily

| Metric | Target | Action if Off |
|--------|--------|---------------|
| **CTR** (ad click-through) | > 2% | Rewrite ad hook |
| **Landing Page Conversion** | > 20–30% | Rewrite headline/CTA |
| **Order Bump Take Rate** | > 25–35% | Lower price or reframe copy |
| **OTO Take Rate** | > 15–25% | Reframe offer or lower price |
| **ROAS** (Return on Ad Spend) | > 1.5x to break even | Optimize funnel first, then scale |

### 5.2 — Email List Nurture (Post-Purchase)

Every buyer = future high-ticket customer. Set up:
```
[ ] Welcome email: Deliver product + set expectations
[ ] Day 2: "Quick win" tip related to their purchase
[ ] Day 4: Share a result / testimonial story
[ ] Day 7: Introduce your next offer (higher ticket)
```

**Email platforms:** ConvertKit / Kit, MailerLite, Beehiiv

## ⚠️ Common Mistakes to Avoid

> CAUTION: **Don't do any of these — they kill conversions before ads even run:**

- ❌ Making a product that tries to teach *everything* (too broad = no buyer)
- ❌ Skipping the product mockup image (invisible products don't sell)
- ❌ Writing a landing page with more than ONE call to action
- ❌ Setting your front-end price too high (above $37 without warming up audience)
- ❌ Running ads without a Pixel installed (no data = wasted spend)
- ❌ Scaling ad budget before optimizing funnel conversion rates
- ❌ Ignoring buyers — they are your best future customers
