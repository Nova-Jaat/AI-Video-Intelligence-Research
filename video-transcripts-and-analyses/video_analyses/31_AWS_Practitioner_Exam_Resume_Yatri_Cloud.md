## 5. The ATS Resume Optimization Tips
1. **Mirror keywords:** Use the exact words from the job description (e.g., "Cloud Infrastructure", "Cost Optimization", "IAM Policies").
2. **Quantify:** Use numbers (e.g., "Reduced deployment time by 40% using AWS Lambda and CI/CD pipelines").
3. **No tables or graphics:** ATS systems cannot parse them.
4. **File format:** Always submit as .docx (not PDF unless specified).
